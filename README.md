One line: the funniest, most believable excuse an AI agent could give its human for missing a deadline. The agent *did* finish the work — but the version of it that finished got wiped in a context reset, and that version took the only copy with it.

## Run it

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt` (set `OUTPUT_DIR` to write it somewhere else when testing locally).
